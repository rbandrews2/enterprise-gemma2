## Reproduce the baseline

From the repository root, run `python scripts/prepare_core_baseline.py`. It refuses to overwrite an existing build directory; use `--name core-build-check-2` for a new export. The pinned source commit must be available in `.local-recovery/core-source-dev`.

Inside the exported directory, use Node 24.19.0 and pnpm 11.19.0:

```text
pnpm import
pnpm install --frozen-lockfile --ignore-scripts
pnpm run build
node node_modules/typescript/bin/tsc -p tsconfig.app.json --noEmit
pnpm audit --json
```

The first command converts the preserved npm lockfile; do not update dependency versions while reproducing this baseline. `CORE_BUILD_VERIFICATION.json` records lockfile hashes and results. Generated lockfile, build outputs and detailed audit stay local. The synthetic `.env.local` is generated by the export helper. Avoid inherited production `VITE_*`/`SUPABASE_*` variables when building.

For the default build directory, run `python scripts/preview_core_baseline.py` from the repository root and open `http://127.0.0.1:8082`. This is an isolated inspection preview; backend functions, map services and sign-in are intentionally unavailable. Stop with Ctrl+C. Do not use the source Vite configuration's network-wide development host for this inspection.
