# Report site imagery — 2026-09-23

Adapted Maps/Street View behavior from services/v2/workspace-job.js into the report workspace. Load site imagery is explicit and sends saved geometry coordinates to Google. Work limits are orange and approach paths blue. The first saved work-limit point, or first approach point, anchors the view; addresses are not geocoded. Missing coordinates disable loading. Report changes clear the display and invalidate pending callbacks. Nearby Street View uses a 50-metre lookup with capture-date and nearby-site warnings; overhead lines are not projected into panoramas. No sign/flagger placements, imagery downloads or snapshot images are created.

Only WZOS_GOOGLE_MAPS_BROWSER_KEY is exposed through the authenticated config route. Server Maps credentials are not read. With a browser key configured, the root HTML uses fresh script/style nonces and the Maps CSP domains; without it, the existing self-only policy remains. Configuration follows https://developers.google.com/maps/documentation/javascript/content-security-policy (checked 2026-09-23). Imagery export/retention policy and production origin configuration remain open gates.
