# V1 live design reference — September 26, 2026

Reviewed the user's signed-in Chrome session at https://app.superiorllc.org.
Read-only navigation through home, time clock, forms hub, work orders, admin,
scheduling, training, messaging and the Atlas drawer. No records submitted,
attendance changed, messages sent or settings modified. Visible features are
design/workflow evidence, not proof their backend or advertised claims work.

## Preserve and refine

- Shared header and persistent icon/text sidebar; modules remain distinct.
- Near-black cards, amber/orange edging, warm text accents, dim road-work imagery.
  Apply the previously selected liquid sheen, gold highlights and dominant gloss
  black to V2, with consistent contrast and reduced-motion support.
- Floating Atlas portrait opens a compact assistant; drawer identifies the current
  module. Carry context-aware help across every module without obstructing actions.
- Separate crew workflows and administrative management. V2 terminology stays
  member/admin only; no separate owner role.

Home also links video conferencing. Admin displays disabled upgrade entries for
Vault, Dispatch and App Integrations. Treat these as inventory items, not completed
V2 functionality or automatic additions to the immediate release scope. Enterprise
dispatch remains governed by the existing dispatch plan.

## V2 design application

1. Functional landing dashboard with module launchers, recent jobs and relevant
   tasks. Keep marketing explanations on workzoneos.org.
2. Consistent sidebar, page heading, primary action, filters and content cards.
   At narrow widths collapse navigation instead of squeezing the working panel.
3. Avoid V1's observed nested sidebar/tab/content scroll regions at the inspected
   narrow desktop viewport; use one clear primary content scroll area.
4. Preserve each module, with Work Zone Report the richer Enterprise workflow:
   linked work order, actual site imagery, reviewed recommendations, diagrams,
   required/recommended forms and package delivery.
5. Place admin controls predictably; backend authorization remains authoritative.
6. Keep Atlas visible and unobtrusive, aware of the module and selected job. Do not
   inherit broad form-data collection merely because V1's greeting advertises it.

Do not copy unverified homepage claims (SOC2 readiness, offline navigation, live
hazard mapping) into V2 promises. The inspected time sheet also contained an
implausibly long synthetic interval: include stale-shift detection and audited
correction review in time-clock acceptance. No individual sample data preserved here.
