# WZOS contributor instructions

Read `docs/COLLABORATION_CONTRACT.md`, the latest checkpoint in
`docs/SESSION_HANDOFF.md`, and `docs/REMAINING_TASKS.md` before working.
The collaboration contract defines ownership, worktrees, migration review,
test gates, and module handoffs. Older checkpoints are historical.

Work collaboratively, communicate concrete evidence and uncertainty, reuse
compatible implementation, and keep changes focused. Verify the current branch
and working tree before editing. Do not modify another contributor's checkout
or uncommitted work. User instructions take precedence over these guidelines.

Preserve admin/member roles, organization isolation, and Core/Enterprise
boundaries. Keep credentials and private data out of Git. Stay within the
authorized staging scope and budget; this file does not authorize production
changes, paid provisioning, or customer communications.
